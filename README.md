# Gian Spinali — Portafolio

Sitio web personal de portafolio, con proyectos de diseño gráfico y desarrollo web realizados entre 2010 y 2020.

**Sitio en vivo:** [gianspinalic.site](https://gianspinalic.site)

## Sobre el portafolio

Archivo de trabajo freelance y como parte del equipo de TECH4Web (agencia brasileña), con proyectos de branding, desarrollo web y tiendas online para clientes en Venezuela, Brasil, Argentina y Chile.

Incluye:

- **Desarrollo web** — sitios corporativos y tiendas online (Hotel Los Bordones, Rimale, Ion Fit, ABGE, Shopping Aloserralheiro)
- **Branding** — identidad de marca y diseño de logo (Ferrecumaná, Germán Bartender)
- **Diseño gráfico** — piezas para redes sociales (Arepas Cochiporki, Doña Arepa, Cicco Dental Service)
